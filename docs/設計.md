# 実装タスク

## 前提

- 使用するライブラリは導入済みの Phaser 4、Vite、TypeScript とする
- 追加ライブラリは使わず、最初は Phaser の図形描画で仮の見た目を作る
- ステージは1面のみとする
- 効果音、ランキング、コイン、複数ステージ、セーブ機能は作らない
- 勝利条件は「ボスを倒した後にゴールへ到達する」とする
- 敗北条件は「プレイヤーのHPが0になる」とする

## タスク1 要件と数値を確定する

- プレイヤー、敵、ボス、弾、ゴール、HUDの役割を確定する
- 操作を確定する
	- Enterキー: タイトルから開始
	- 左右矢印キー: 移動
	- 上矢印キー: ジャンプ
	- Aキー: 射撃
- 初期HP、移動速度、ジャンプ力、弾の攻撃力、敵の攻撃間隔を決める
- 敵は感知範囲にプレイヤーが入ると攻撃する仕様にする
- 時間は経過時間をHUDに表示し、制限時間は設けない

## タスク2 シーン構成を作る

- `TitleScene` を作り、Enterキーで `GameScene` へ遷移する
- `GameScene` を作り、ゲーム本編の起点にする
- `ResultScene` を作り、勝利・敗北を表示する
- 敗北時はリトライまたはタイトルへ戻れるようにする
- 勝利時はご褒美シーン（R12）を表示し、タイトルへ戻れるようにする
- `main.ts` のシーン配列に登録する

### 完了条件

タイトル、プレイ、勝利、敗北の画面遷移を仮表示で確認できる。

## タスク3 プレイ画面とステージを作る

- Phaser の物理システムを有効にする
- 地面、足場、壁を図形で配置する
- プレイヤーの開始位置を設定する
- 通常の敵、ボス、ゴールの配置場所を設定する
- 横長ステージのカメラをプレイヤーに追従させる
- HUDをカメラ固定で表示する

### 完了条件

プレイヤーが横長のステージを移動でき、カメラも追従する。

## タスク4 プレイヤーを実装する

- 左右矢印キーで移動する
- 上矢印キーでジャンプする
- 地面と足場に衝突する
- プレイヤーのHPを管理する
- ダメージを受けた後の無敵時間を設定する
- 穴に落ちた場合は敗北にする

### プレイヤーの状態

- 待機
- 移動
- ジャンプ
- ダメージ
- 撃破

### 完了条件

移動、ジャンプ、落下、ダメージ、HP0の判定を確認できる。

## タスク5 銃と弾を実装する

- Aキーでプレイヤーの向いている方向へ弾を発射する
- 弾に速度と攻撃力を設定する
- 弾と敵・ボスの衝突判定を作る
- 画面外へ出た弾を削除する
- 連射間隔を設定する

### 完了条件

弾が発射され、敵またはボスに当たるとHPが減る。

## タスク6 通常の敵を実装する

- 敵のHP、移動速度、攻撃力を設定する
- プレイヤーの感知範囲を設定する
- 感知範囲に入ると敵の弾を発射する
- 敵の弾がプレイヤーに当たるとHPを減らす
- 敵のHPが0になると敵を消す

### 敵の状態

- 待機
- 攻撃準備
- 攻撃
- ダメージ
- 撃破

### 完了条件

敵がプレイヤーを感知して攻撃し、プレイヤーの弾で倒せる。

## タスク7 ボスを実装する

- ボスのHPと攻撃力を設定する
- ボスエリアへ入ると戦闘を開始する
- 一定間隔でボスの弾を発射する
- プレイヤーの弾でボスのHPを減らす
- ボスのHPが0になると撃破する
- ボス撃破後にゴールを有効にする

### ボスの状態

- 登場前
- 戦闘
- 攻撃
- ダメージ
- 撃破

### 完了条件

ボスを倒す前はゴールできず、倒した後だけゴールできる。

## タスク8 勝敗とHUDを実装する

- HUDにプレイヤーHPを表示する
- HUDに経過時間を表示する
- HUDに操作方法を表示する
- ボス戦中だけボスHPを表示する
- HPが0になったら `ResultScene` に敗北結果を渡す
- ボス撃破後にゴールへ触れたら勝利結果を渡す
- 勝敗確定後にプレイ中の更新を停止する

### 完了条件

「HP0で敗北」「ボス撃破後のゴール到達で勝利」が再現できる。

## タスク9 見た目を整える

- 仮の図形を必要に応じて画像素材へ置き換える
- プレイヤー、敵、ボス、弾、ゴールを色で区別する
- HPバーとボスHPバーを見やすくする
- 勝利画面にご褒美を表示する
- 画面サイズに合わせてレイアウトを調整する

## タスク10 動作確認と完成判定

- タイトルからプレイ画面へ遷移できる
- 左右移動、ジャンプ、射撃ができる
- 敵が攻撃し、敵を倒せる
- ボスを倒せる
- ボス撃破前のゴール到達が勝利にならない
- ボス撃破後のゴール到達が勝利になる
- HP0で敗北になる
- 勝利・敗北からリトライまたはタイトルへ戻れる
- `npm run typecheck` が成功する
- `npm run build` が成功する

## 実装予定のファイル

```text
src/

	config/
		gameConstants.ts
	scenes/
		TitleScene.ts
		GameScene.ts
		ResultScene.ts
	objects/
		Player.ts
		Enemy.ts
		Boss.ts
		Bullet.ts
```

## 実装順の区切り

1. タスク1からタスク3までで、画面遷移とステージを表示する
2. タスク4とタスク5で、移動・ジャンプ・射撃を完成させる
3. タスク6とタスク7で、敵とボスの戦闘を完成させる
4. タスク8で勝敗とHUDを接続する
5. タスク9とタスク10で見た目と完成確認を行う
